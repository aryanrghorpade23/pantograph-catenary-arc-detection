# Project figures

Six MATLAB figure screenshots were supplied for the project:

1. Real pantograph voltage, pantograph current and input-filter output voltage.
2. Baseline and selected event voltage intervals.
3. Baseline and transient FFT spectra.
4. STFT spectrogram of the real pantograph voltage.
5. db4 wavelet detail coefficients D1–D5.
6. Sliding-window features and real-data diagnostic results.

The screenshots are retained with the project files locally. They are not included as individual image assets in this initial GitHub snapshot; add the corresponding PNGs to this folder when uploading the image files through GitHub.
